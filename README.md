# Experiment 10: Building a Simple LLM Chatbot

**Roll Number:** 24BAD098

## Description
This project implements a simple, fully functional interactive AI Chatbot using the Qwen 2.5 (0.5B Instruct) language model. The interface is built with Gradio and runs seamlessly inside a Google Colab notebook environment.

## Features
- Real-time interaction with a Hugging Face LLM (`Qwen/Qwen2.5-0.5B-Instruct`)
- Clean and simplified Gradio interface using Markdown blocks to track the conversation history securely
- Prompt testing scripts included
- Automatic handling of conversation memory
